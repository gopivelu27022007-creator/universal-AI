# 🌟 Universal AI Chatbot (அகில உலக AI உதவியாளர்)

An advanced, modern, high-performance Universal AI Chatbot web application built to answer questions accurately and quickly across **all 18 academic, technical, and general domains** in **Tamil** and **English**.

---

## ✨ Features (சிறப்பம்சங்கள்)

1. **Prompt Implementation**:
   - Built directly on the **Universal AI Chatbot Prompt**.
   - Responds in the user's language (**Tamil / English / Tanglish**).
   - Speed metric badge on every response (**⚡ &lt;5s**).
   - Structured response format: *Direct answer -> Explanation -> Examples -> Suggestions*.

2. **18 Domains Supported**:
   - 🎓 **School Subjects:** Maths, Physics, Chemistry, Biology, Social Science, Tamil, English, Computer Science.
   - 🏛️ **College & Engineering:** AI, Data Structures, DBMS, Networking, OS, Mechanical, Civil, EEE, ECE.
   - 💻 **Technical Topics:** HTML, CSS, JavaScript, React, Python, C++, Java, Node.js, SQL, Cloud, DevOps, Git.
   - 🌐 **Non-Technical Topics:** History, Geography, Economics, Health, Sports, Books, Movies.
   - 🧠 **Aptitude & Logical Reasoning:** Step-by-step math proofs & formulas.
   - 💼 **Career & Interviews:** HR questions, resume advice, project recommendations.
   - 📜 **Tamil Language & Literature:** திருக்குறள், இலக்கணம், இலக்கிய நயங்கள்.
   - 🕒 **Real-Time Date & Time:** Live local date and time responses.

3. **Audio & Voice Capabilities**:
   - 🎙️ **Voice Input (Speech-to-Text):** Speak in Tamil or English to dictate questions.
   - 🔊 **Voice Output (Text-to-Speech):** Listen to the chatbot's answers read aloud.

4. **Dual Engine Support**:
   - **Google Gemini 1.5 / 2.0 Direct API:** Connect your free Gemini API key in settings for live web-scale intelligence.
   - **Smart Built-in Offline Engine:** Works instantly even without an API key with built-in domain solvers.

5. **Modern Aesthetics**:
   - Glassmorphic dark and light theme toggle.
   - Markdown formatting with code syntax highlighting & one-click code copy button.
   - Chat history management & Markdown export.
   - 100% responsive for desktop, tablet, and mobile.

---

## 🚀 How to Run (இயக்குவது எப்படி)

No server or npm installation is required!

1. Open the folder: `c:\Users\ELCOT\Desktop\chatbot 2`
2. Simply **double-click** `index.html` to open it in any modern browser (Google Chrome, Microsoft Edge, Brave, Firefox).
3. (Optional) Click **API Settings** in the sidebar to add your free Gemini API Key from [Google AI Studio](https://aistudio.google.com/app/apikey).
